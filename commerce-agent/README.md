# 电商创作 Agent

状态：迁移实施中，尚未完成真实用户验收。2026-10-08。

## 本轮目标

交付一个运行在 OpenClaw 的可安装 Agent 包。用户从原生对话提交文字、商品图或视频，Agent 自己理解需求、读取相应 Skill、选择工具、观察真实媒体、执行制作、检查产物并继续修改。主入口不依赖 `video-agent/server.mjs`、旧 WebUI 或第二个规划 Agent。

当前用户指令取代旧合同中“必须沿用视频后端作为主执行器”和“暂停新的图片/视频生成”的架构限制。旧代码、素材、未提交修改、历史工程和原版本的验收记录全部保留；本轮迁移不把历史欠项改成通过。八个业务场景、生成/编辑/声音/恢复/交付能力仍须逐项验证。

## 职责

| 部分 | 职责 |
|---|---|
| OpenClaw | 唯一的对话、理解、规划和工具执行主体 |
| 本包 Skills | 商品事实、场景方法、生成选择、局部修改及交付规则 |
| RHClaw 客户端 | 复用锁定版本的 RunningHub API 能力；不照搬其模型选择菜单 |
| 本地媒体工具 | 确定性探测、抽帧、剪辑、字幕、混音和导出，不调用另一个规划模型 |
| 任务文件 | 输入、工具回执、供应商任务 ID、输出版本及局部修改关系 |
| 旧 HyperFrames | 保留工程与历史；按需要作为可选合成工具，不是图片任务前置条件 |

首轮无需单独账号系统、数据库、编辑器、工作流画布或自研 RAG 服务。商品资料通过当前任务文件按需读取；只有检索规模确实需要时才增加索引。

## 实施与验收顺序

1. 核对当前环境与实际调用链，保存基线；实现独立安装、能力探测与真实 OpenClaw 工具加载。
2. 接入 RunningHub 的查询、提交、轮询和交付；固定真实工作流/端点，缺少配置明确报告。提交结果不确定时先对账，禁止自动重复收费。
3. 接入本地媒体观察、剪辑、图文合成及声音；将规划放在 Agent，工具只执行明确输入。
4. 跑通原生页面的文字、图片、视频输入与可下载输出，再做同一会话局部续改、刷新恢复与失败处理。
5. 用真实素材验证八场景及保持约束；对标样本未取得前，不宣称达到竞品水平。

`acceptance.json` 是本轮完整验收清单；每项必须有当前版本真实证据，不能只通过静态检查、Mock 或 Agent 自述完成。

## 初始发现

- 旧控制 Agent 只有九个 `video_*` 工具，禁止 read/exec 等通用能力；Skill 要求读取文件与工具边界冲突。
- 插件通过 HTTP 回调旧视频后端，后端再调规划阶段，增加路由、授权、会话和恢复的重复状态。
- 2026-10-08 启动检查：旧 Gateway 不可达，18789/3024/3020 无监听；没有据此重启任何历史任务。
- 本地存在 OpenClaw 2026.6.11 与 FFmpeg/FFprobe，可复用；HyperFrames 保持 0.8.33。

## 完成定义

同一原生对话入口，真实输入进入正确工具，生成或编辑出真实媒体，用户能打开与下载，并能继续指定修改且保持其余内容。重启后任务可核对、恢复，不重复生成或假报成功。图像、视频、声音的媒体技术检查与实际视觉/听感判断分开记录。

## 本机使用

```sh
python3 commerce-agent/launcher.py install
python3 commerce-agent/launcher.py gateway
```

另一个终端执行 `python3 commerce-agent/launcher.py cli dashboard` 打开 OpenClaw 原生聊天。当前安装在 `~/.openclaw/commerce-agent/`；源码、Skill、FFmpeg/FFprobe 已复制到仓库外，执行不需要启动旧视频后端。Gateway 占用本机 18789，启动器发现已有监听会停止，不覆盖其他运行实例。旧项目未删除、迁移或重启。

本机配置加载顺序为原有 OpenClaw 主机配置、新包的 `~/.openclaw/commerce-agent/environment.json`、进程环境；后者优先。新配置文件只保存在私人目录，权限应为 0600，不提交仓库、不粘贴到聊天。RunningHub 使用 `RUNNINGHUB_API_KEY`；收费执行还需要 `COMMERCE_GENERATION_BUDGET_CNY` 和按端点保存、经核对的 `COMMERCE_COST_CEILINGS_JSON`。预算默认关闭，目录查询不会触发生成。

测试与当前记录：

```sh
python3 -m unittest discover -s commerce-agent/tests -v
node commerce-agent/tests/openclaw-loader.mjs
```

`tests/verify_live.py` 是显式调用真实模型的本地媒体验收脚本，可能产生已有主模型的调用费用，不运行收费媒体生成。它上传现有视频，要求 Agent 自行读取 Skill、检查、制作并交付；`edit` 参数用于同一会话局部续改。Gateway 失败时不自动另开执行会话。当前记录在 `evidence/live-local/`，属于运行证据，不作为业务源码。
