# R0–R12 stage map

R0 admission/policy → R1 brief → R2 material → R3 creative direction → R4 story/source selection → R5 resource planning → R6 native scene production → R7 preview review → R8 scoped repair → R9 render → R10 final quality → R11 human acceptance → R12 delivery. Each stage has an artifact, receipt, hash and checkpoint. Candidate output is allowed before human review; formal delivery remains fail-closed.
