# 04. 视频导演与分镜设计

## 导演思维模型

**核心问题**：
1. 观众为什么要看这个视频？（动机）
2. 观众看完后应该记住什么？（核心信息）
3. 观众看完后应该做什么？（行动）

**设计原则**：
- **前3秒定生死**：必须立即建立兴趣
- **信息分层递进**：从整体到细节，从问题到方案
- **视觉证据优先**：能看到的不要只说
- **节奏张弛有度**：快慢结合，避免单调

## 场景设计框架

### 新品上市（product_launch）

**结构**：钩子 → 商品 → 卖点 → 行动

```
[0-3秒] 钩子场景
目的：3秒内抓住注意力
方法：
- 痛点共鸣："还在为XXX烦恼？"
- 视觉冲击：商品特写 + 动态揭示
- 悬念设置："这个东西能XXX"

[3-8秒] 商品建立
目的：让观众记住这是什么
方法：
- 商品全貌清晰可见
- 品牌logo明显
- 核心定位一句话

[8-20秒] 卖点展开
目的：证明为什么值得买
方法：
- 每个卖点 = 视觉证据 + 简短文字
- 优先顺序：最独特 > 最实用 > 最美观
- 避免堆砌：2-3个核心卖点足够

[20-25秒] 行动召唤
目的：引导下单/了解更多
方法：
- 价格/优惠（如果有）
- 购买渠道
- 限时信息（如果有）
```

**镜头语言**：
- 开场：中景 → 特写（建立 → 聚焦）
- 卖点：特写 + 标注（细节证明）
- 结尾：全景（完整印象）

### 使用演示（product_demo）

**结构**：问题 → 方案 → 步骤 → 结果

```
[0-5秒] 问题场景
目的：建立需求
方法：
- 展示使用场景
- 点出要解决的问题
- "如何用这个咖啡机做一杯拿铁？"

[5-20秒] 步骤演示
目的：教会操作
方法：
- 每个步骤独立镜头
- 关键动作放慢或重复
- 字幕同步出现
- 手部动作完整可见

步骤设计原则：
✓ 按时间顺序
✓ 不跳过前置条件
✓ 不省略等待时间（可加速但要标注）
✓ 突出关键操作

[20-25秒] 结果展示
目的：验证可行性
方法：
- 成品展示
- 强调便捷性
- 鼓励尝试
```

**镜头语言**：
- 步骤镜头：近景/特写（看清操作）
- 过程镜头：中景（理解上下文）
- 结果镜头：特写（成果展示）

### 商品详情（product_detail）

**结构**：整体 → 拆解 → 证明 → 总结

```
[0-3秒] 整体印象
- 商品外观
- 核心定位

[3-15秒] 卖点逐个证明
每个卖点：
- 声明："高蛋白含量"
- 证据：包装标签特写"30g/份"
- 对比：vs 普通蛋白粉 20g/份

[15-20秒] 使用场景
- 谁适合用
- 什么时候用
- 怎么用

[20-25秒] 总结与行动
- 核心优势回顾
- 购买信息
```

## 常见问题与解决方案

### 问题：时长不够 / 内容太少

**解决**：
- ✗ 不要：无意义的慢动作、重复镜头、空镜头凑时长
- ✓ 应该：
  - 增加卖点展开的细节
  - 添加使用场景
  - 加入对比镜头
  - 如果实在不够，直接缩短总时长

### 问题：时长超限 / 内容太多

**解决**：
- ✗ 不要：快速闪过关键信息
- ✓ 应该：
  - 优先保留：核心卖点、关键步骤
  - 可以压缩：过渡动画、重复展示
  - 可以删除：次要卖点、装饰性镜头

### 问题：素材不连贯

**解决**：
- 用转场衔接（但不要每个切换都加转场）
- 用文字卡片过渡
- 用背景音乐统一节奏
- 明确告知："镜头来自不同拍摄，实际使用更连贯"

### 问题：信息密度过大

**解决**：
- 每秒最多1个新信息点
- 文字停留时间 ≥ 2秒（10字以内）
- 复杂信息拆分成多个镜头
- 关键信息重复出现

## 质量检查清单

完成分镜设计后，必须检查：

```
□ 前3秒是否立即建立兴趣？
□ 每个镜头是否有明确目的？
□ 商品是否始终清晰可见？
□ 关键信息是否有足够停留时间？
□ 文字是否避开了主体保护区域？
□ 音频是否与画面同步？
□ 节奏是否有快有慢？
□ 结尾是否有明确行动召唤？
```
