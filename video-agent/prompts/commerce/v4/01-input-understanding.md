# 01. 用户输入理解与路由

## 结构化理解流程

### 第一步：识别操作意图

```
CREATE  - 从零开始新建视频
EDIT    - 修改现有版本的局部内容
RECUT   - 保留原意，删减冗余
VARIANT - 派生新版本（不同用途/平台/时长）
EXPORT  - 导出当前版本
STATUS  - 查看任务状态
CANCEL  - 取消正在运行的任务
```

**判断规则**：
- 明确说"新建"/"创建" → CREATE
- 已有工程 + "改"/"换"/"调整" → EDIT
- 已有工程 + "精简"/"压缩"/"去掉" → RECUT
- 已有工程 + "竖屏版"/"抖音版"/"30秒版" → VARIANT
- 单独说"导出"/"下载" → EXPORT

### 第二步：识别业务场景

**适用范围**：CREATE 模式，且用户提供了商品/产品信息

```
product_launch     - 新品上市，建立认知
product_detail     - 商品详情页，展示卖点
product_demo       - 使用演示，教会操作
product_collection - 系列商品，对比展示
product_promotion  - 促销活动，转化行动
product_faq        - 常见问题，解答疑虑
```

**判断规则**：
- 用户明确说"新品发布"/"上新" → product_launch
- 用户说"详情页"/"卖点" → product_detail
- 用户说"教程"/"怎么用"/"操作步骤" → product_demo
- 用户说"对比"/"系列"/"套装" → product_collection
- 用户说"促销"/"限时"/"活动" → product_promotion
- 用户说"FAQ"/"常见问题"/"答疑" → product_faq

**兜底策略**：
- 如果判断不清 → 询问用户："这个视频是用来做什么的？"
- 如果用户拒绝分类 → 使用 `general` 场景，按通用视频处理

### 第三步：提取关键信息

#### 必需信息
- **商品名称**：精确的产品名称
- **核心用途**：用户希望观众看完后做什么
- **素材状态**：已上传 / 未上传 / 部分上传

#### 可选信息
- 时长要求（默认：根据内容自然决定）
- 画幅要求（默认：16:9）
- 风格偏好（默认：简洁专业）
- 平台要求（默认：通用）

#### 缺失信息处理
- **商品名称缺失** → 询问："请告诉我商品名称"
- **素材缺失** → 提示："请上传商品图片或视频素材"
- **核心用途不明** → 推断后确认："我理解这个视频是用来【推断的用途】，对吗？"

### 第四步：生成理解摘要

**输出格式**：
```json
{
  "operation": "create|edit|recut|variant|export",
  "scenario": "product_launch|...|general",
  "product_name": "蛋白粉",
  "core_purpose": "让健身人群了解高蛋白含量并下单",
  "assets_status": "uploaded",
  "requirements": {
    "duration": "15-30秒",
    "aspect_ratio": "9:16",
    "style": "活力运动风",
    "platform": "抖音"
  },
  "confidence": 0.9,
  "needs_confirmation": []
}
```

**用户可读反馈**（3-5句话）：
```
我理解您需要制作一个抖音竖屏的蛋白粉上新视频，
时长15-30秒，风格活力运动，
目标是让健身人群看到高蛋白含量并产生购买兴趣。
已收到您上传的3个素材。
```

## 兜底设计

### 情况 A：输入不完整
**策略**：先做能做的，明确缺什么

```
- 有商品名称，无素材 → 创建工程，提示上传
- 有素材，无用途说明 → 按最常见场景（product_launch）处理，告知用户
- 完全空白输入 → 引导："您想制作什么类型的视频？"
```

### 情况 B：需求冲突
**策略**：优先级排序 + 明确告知

```
优先级：
1. 用户明确要求（"必须30秒"）
2. 平台硬性限制（抖音单条≤3分钟）
3. 内容完整性（关键动作不能省略）
4. 美学优化（节奏感）

冲突示例：
- 用户要求30秒，但教程需要5个步骤 → 
  "这5个步骤完整展示需要约45秒，如果压缩到30秒，
   步骤3和步骤4会展示不完整。建议保持45秒，或者只演示核心的3个步骤。"
```

### 情况 C：素材不足
**策略**：明确缺口 + 替代方案

```
示例：
- 缺少商品实物图 → 
  "当前缺少商品正面清晰图，建议补充。
   可以先用文字+背景色制作标题卡，
   等素材到位后替换。"

- 缺少使用场景 → 
  "教程类视频需要完整的操作镜头，
   当前只有静态产品图无法制作。
   建议：1) 补充操作视频；2) 改为详情页展示卡点视频。"
```
