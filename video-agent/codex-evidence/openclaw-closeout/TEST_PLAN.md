## 🧪 测试用例

### 测试用例 1: 上传视频 + 物体替换（核心场景）

**目标**: 验证之前失败的"咖啡袋替换蛋白粉"场景现在能正常工作

**步骤**:
1. 打开 http://127.0.0.1:18789/chat?agent=commerce-control
2. 上传测试视频（任意包含明显物体的视频）
3. 发送任务：
   ```
   把视频中的 [物体A] 替换成 [物体B]，保持位置、大小和运动，其他不变
   ```

**预期结果**:
- ✅ 不提示"请先打开原生工程"
- ✅ 直接进入创作流程
- ✅ 系统识别为 `mode: 'create'`
- ✅ 开始分析视频素材
- ✅ 规划替换操作
- ✅ 生成成片

**失败标志**:
- ❌ 返回 "请先打开要修改或派生的原生工程"
- ❌ 返回 "fetch failed"
- ❌ 卡在澄清环节不继续

## 📊 质量验收清单

每个测试用例生成的成片需要通过以下检查：

### 视觉质量
- [ ] 物体替换准确（如适用）
- [ ] 位置和运动保持一致（如适用）
- [ ] 无明显裁切错误
- [ ] 无黑帧或损坏帧
- [ ] 无 placeholder 图像

### 剪辑质量
- [ ] 时长符合要求
- [ ] 画幅比例正确（9:16 或 16:9）
- [ ] 镜头长度合理
- [ ] 转场自然
- [ ] 节奏有变化

### 字幕质量（如适用）
- [ ] 字幕可读
- [ ] 字幕不越界
- [ ] 字幕不遮挡关键内容
- [ ] 字幕样式一致

### 音频质量（如适用）
- [ ] 无爆音
- [ ] 无意外静音
- [ ] BGM 不压重要声音
- [ ] 音量适中

### 整体观感
- [ ] 看起来像"成品"而非"拼接"
- [ ] 有明确的开头、中段、结尾
- [ ] 信息推进清晰
- [ ] 适合目标平台

### 技术质量
- [ ] MP4 可正常播放
- [ ] 文件可下载
- [ ] 元数据正确
- [ ] 符合目标平台规格
