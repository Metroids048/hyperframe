## 本轮发现并修复的问题

- 原实现只接 API Key：切换默认为已登录的 Codex 订阅，并处理 Windows 系统代理的子进程传递。
- 删除开头的二次移动：模型不再为自动同步额外改字幕时间，复合清单执行前校验。
- 旁白字幕与宣传字幕重叠：按实际文字尺寸和重叠时间分层，保留两段内容。
- 同一句“配音并加字幕”看不到新音轨：先生成新语音，再转写本轮语音；替换旁白的字幕也使用新音频。
- 默认中文音素发音不准：使用 Misaki 中文前端配合 HyperFrames Kokoro 模型；“欢迎体验我们的新品”独立转写回读一致。
- 原入口跳到手动 Studio / 下载原片：现已进入嵌入聊天编辑器，用对应版本的导出控件。
