## 第一轮验收：完整制作

### 目标
制作约 40 秒、1080×1920 竖屏商品推广片，包含：
- 6-8 个有效镜头，至少 5 个不同源区间
- 开头展示使用动作
- 商品特点和使用过程
- 至少两种 HyperFrames 表达（如细节放大标注、分屏对比）
- 自然中文讲解、同步字幕与合适音乐

### 操作步骤

1. **上传素材**
   - 点击输入框旁的上传按钮
   - 选择商品视频文件
   - 等待上传完成（显示文件名）

2. **发送制作请求**
   
   在输入框输入（根据实际素材调整）：
   ```
   请为这个商品视频制作一个40秒左右的竖屏推广片，要求：
   1. 筛选6-8个有效镜头，至少使用5个不同的源视频区间
   2. 开头展示真实使用动作，然后展开商品特点和完整使用过程
   3. 使用至少两种有信息价值的视觉设计，比如细节放大标注、整体与细节分屏对比
   4. 统一字体、配色和节奏
   5. 加入自然的中文讲解、同步字幕和合适的背景音乐
   6. 人声时降低音乐音量
   7. 1080×1920竖屏输出
   
   请自动完成制作并交付成片。
   ```

3. **观察进度**
   - ✓ 显示任务已创建（status: queued 或 running）
   - ✓ 显示项目 ID 和任务 ID
   - ✓ 阶段更新（如"理解需求"、"规划镜头"、"生成音频"等）
   - ⚠️ 不应该显示 "Tool error" 或 "ERROR"

4. **等待完成**
   - 预期时间：10 分钟内
   - 完成后应自动显示视频播放器或下载链接

5. **验证结果**
   - [ ] 下载生成的 MP4 文件
   - [ ] 完整观看视频
   - [ ] 检查镜头数量和源区间多样性
   - [ ] 验证讲解、字幕和音乐都存在
   - [ ] 记录时长、分辨率和文件大小

### 评分标准（总分 100，及格线 85）

| 项目 | 满分 | 评分要点 |
|------|------|----------|
| 叙事结构 | 20 | 开头-特点-使用过程-结尾流畅，逻辑清晰 |
| 镜头节奏 | 20 | 6-8 镜头，节奏合理，无突兀跳切 |
| 视觉与 HyperFrames | 25 | 至少两种有信息价值的视觉设计，标注/分屏清晰 |
| 声音字幕 | 20 | 讲解自然、字幕同步、音乐合适、混音正确 |
| 连续性与完成度 | 15 | 完整成片、无黑帧/错位、符合要求 |

**硬伤（出现任一项即判定失败）**：
- 商品信息错误
- 核心要求漏做（如无讲解、无字幕、无音乐）
- 明显遮挡、黑帧或字幕错位
- 配音被音乐完全盖住
- 原片简单加字冒充完整制作

## 第二轮验收：实质重剪

### 目标
在第一轮成片基础上进行实质性重新剪辑：
- 调整开头和叙事顺序
- 替换两处重复镜头
- 将一处特点展示改成不同版式
- 同步更新相关讲解和字幕
- 保持商品事实、未涉及镜头、音乐曲目、结尾、时长范围和输出规格

### 操作步骤

1. **在同一会话继续**（不要刷新页面）

2. **发送重剪请求**
   ```
   请对刚才的视频进行重剪：
   1. 把开头的使用演示和第3-4个镜头调换顺序
   2. 替换掉两处重复出现的镜头，用其他源区间代替
   3. 把[具体某处]的展示方式从[当前版式]改成[不同版式]
   4. 相应更新受影响部分的讲解和字幕
   5. 保持商品事实、背景音乐曲目、结尾引导、时长40秒左右和竖屏规格不变
   ```

3. **观察进度**
   - ✓ 识别出这是编辑现有视频
   - ✓ 显示新的任务 ID
   - ✓ 阶段更新

4. **验证结果**
   - [ ] 下载新生成的视频
   - [ ] 对比第一版，确认顺序确实改变
   - [ ] 确认新镜头已替换旧镜头
   - [ ] 确认版式改变生效
   - [ ] 确认讲解和字幕与新顺序匹配
   - [ ] 确认保持项未被破坏（音乐、结尾、时长）

### 评分标准
- 改变项必须真实体现
- 保持项不能被破坏
- 新版本内部一致（画面、声音、字幕同步）

## 第三轮验收：选择性恢复

### 目标
只恢复第一版某段的转场或布局，同时保留第二版的新镜头、新顺序和新讲解。

### 操作步骤

1. **在同一会话继续**

2. **发送恢复请求**
   ```
   请恢复第一版中[具体某段，如"第3-4个镜头之间的转场效果"]，
   但保留第二版的新镜头顺序、新镜头选择和更新后的讲解字幕，
   不要整体回滚到第一版。
   ```

3. **验证结果**
   - [ ] 指定的转场/布局确实恢复
   - [ ] 第二版的镜头顺序保持
   - [ ] 第二版的讲解和字幕保持
   - [ ] 不是整体回滚

## 故障排查

### 问题：Tool error 或 ERROR
```bash
# 1. 检查服务日志
tail -50 server.log

# 2. 检查授权
cat ~/.openclaw/hyperframe/environment.json | grep OPENCLAW_BRIDGE_TOKEN

# 3. 重启服务
kill $(cat .server.pid)
/Users/a1234/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node server.mjs > server.log 2>&1 &
echo $! > .server.pid
```

### 问题：任务卡住不动
```bash
# 查看任务状态
curl -s http://127.0.0.1:3020/api/commerce/[项目ID] | python3 -m json.tool
```

### 问题：视频无法下载
检查文件是否生成：
```bash
find ~/.openclaw/hyperframe/state/projects -name "commerce-final.mp4" -mmin -30
```
