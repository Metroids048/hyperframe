# OpenClaw WebUI 端到端测试指南

## 环境检查

### 1. 确认服务运行
```bash
# Video Agent (端口 3020)
curl http://127.0.0.1:3020/api/health

# OpenClaw Gateway (端口 18789)
curl http://127.0.0.1:18789/health
```

### 2. 准备测试素材
确保存在视频文件：
- `视频样例_蛋白粉版.mp4`（已上传）
- 或 `assets/edit-samples/product.mp4`

---

## 测试场景：产品营销视频多轮精修

### 第一轮：创建基础版本

**操作步骤：**
1. 打开浏览器访问：http://localhost:18789
2. 点击"新建项目"或"Create New Project"
3. 上传视频：`视频样例_蛋白粉版.mp4`
4. 在对话框输入：
   ```
   制作一个15秒的产品营销视频，要求：
   - 提取最精彩的片段
   - 添加醒目标题"健康蛋白 活力满分"
   - 配合轻快的背景音乐
   - 节奏紧凑，突出产品特点
   ```
5. 点击"生成"或"Generate"

**验收标准：**
- ✅ 视频成功生成
- ✅ 时长约15秒
- ✅ 包含标题文字
- ✅ 有背景音乐
- ✅ 画面流畅，无卡顿

---

### 第二轮：优化标题样式

**操作步骤：**
在对话框继续输入：
```
把标题样式优化一下：
- 字体改大，更醒目
- 颜色改成红色渐变
- 位置移到画面上方居中
- 添加白色描边，提升可读性
```

**验收标准：**
- ✅ 标题样式更新正确
- ✅ 其他内容保持不变
- ✅ 响应时间 < 30秒
- ✅ 视觉效果提升明显

---

### 第三轮：调整内容节奏

**操作步骤：**
继续输入：
```
调整视频节奏：
- 前5秒：快节奏展示产品外观，配合快速剪辑
- 中间5秒：放慢节奏，特写产品使用场景
- 后5秒：加快节奏，展示多个使用效果，营造冲击力
```

**验收标准：**
- ✅ 视频节奏明显变化
- ✅ 三段节奏清晰可辨
- ✅ 转场自然流畅
- ✅ 音乐节奏匹配画面

---

### 第四轮：添加字幕和特效

**操作步骤：**
继续输入：
```
在关键镜头添加说明：
- 产品特写时显示"天然成分 零添加"
- 使用场景显示"随时随地 轻松补充"
- 效果展示显示"健康生活 从此开始"
所有字幕使用渐入渐出动画，停留2秒
```

**验收标准：**
- ✅ 三处字幕时机准确
- ✅ 动画效果流畅
- ✅ 字幕清晰可读
- ✅ 不遮挡主要内容

---

### 第五轮：最终优化和导出

**操作步骤：**
继续输入：
```
最后的优化：
- 背景音乐换成更有激情的风格
- 整体色调调亮10%，更清新明快
- 在视频结尾添加产品logo定格1秒
- 导出1080p高清版本
```

**验收标准：**
- ✅ 音乐风格明显改变
- ✅ 色调调整自然
- ✅ logo显示清晰
- ✅ 导出成功，画质无损

## 异常场景测试

### 测试1：素材不符合要求
上传纯图片文件，验证错误提示是否清晰友好。

**预期结果：**
```
❌ 素材不符合要求
请上传真实的产品演示视频。图片素材仅用于需求理解。

建议：
- 上传展示产品使用过程的视频
- 确保视频清晰展示产品特点
- 视频时长建议 10 秒以上
```

### 测试2：模糊指令
输入："改好看点"

**预期结果：**
系统提示：
```
需要更具体的描述。可以告诉我：
- 要改什么？（标题、画面、音乐、节奏）
- 怎么改？（颜色、大小、位置、风格）
- 期望效果？（更醒目、更柔和、更专业）

例如："把标题字体改大，颜色改成红色，更醒目"
```

### 测试3：任务超时
提交一个复杂任务，模拟超时场景。

**预期结果：**
- 显示进度条或状态更新
- 超时后给出明确提示
- 提供重试选项

## 质量评估标准

### 视觉质量
- [ ] 分辨率 ≥ 1080p
- [ ] 画面清晰，无模糊
- [ ] 色彩自然，无过曝/欠曝
- [ ] 文字清晰可读
- [ ] 动画流畅，帧率稳定

### 听觉质量
- [ ] 音频清晰，无杂音
- [ ] 背景音乐音量适中
- [ ] 音乐风格匹配内容
- [ ] 音画同步准确

### 交互体验
- [ ] 响应及时（单次 < 30秒）
- [ ] 状态反馈清晰
- [ ] 错误提示友好
- [ ] 可以随时修改
- [ ] 支持历史版本回退

### 稳定性
- [ ] 连续5轮编辑无崩溃
- [ ] 多个项目并行无冲突
- [ ] 长时间运行内存稳定
- [ ] 网络波动可恢复
