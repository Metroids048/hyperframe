# OpenClaw 视频编辑系统 - 测试清单

## 回归测试执行指南

本文档提供完整的测试清单，用于验证 OpenClaw 视频编辑系统的核心功能。

## 前置条件

### 环境准备

- [ ] Node.js 已安装（v18+）
- [ ] 依赖包已安装（`npm install`）
- [ ] Video Agent 服务运行在 `http://127.0.0.1:3020`
- [ ] OpenClaw Gateway 服务运行在 `http://127.0.0.1:18789`

**启动服务**:
```bash
# 在 video-agent 目录
npm start

# 验证服务状态
curl http://127.0.0.1:3020/health
curl http://127.0.0.1:18789/health
```

### 测试素材准备

- [ ] 测试视频文件存在：`../视频样例_蛋白粉版.mp4`
- [ ] 视频格式：MP4
- [ ] 视频时长：30+ 秒
- [ ] 视频分辨率：1920x1080 或更高

## 质量验证

### QV01: 视频质量检查清单

对每个生成的视频执行以下检查：

- [ ] **分辨率**: 1080x1920 (竖屏)
- [ ] **帧率**: 30 FPS
- [ ] **编码**: H.264
- [ ] **音频**: AAC
- [ ] **时长**: 符合预期（15±2 秒）
- [ ] **文件大小**: 合理（< 10 MB）
- [ ] **播放流畅**: 无卡顿
- [ ] **音画同步**: 无延迟
- [ ] **标题清晰**: 可读性好
- [ ] **颜色准确**: 无失真

**检查命令**:
```bash
ffprobe -v error -select_streams v:0 \
  -show_entries stream=width,height,r_frame_rate,codec_name \
  -of default=noprint_wrappers=1 commerce-final.mp4

ffprobe -v error -select_streams a:0 \
  -show_entries stream=codec_name,sample_rate \
  -of default=noprint_wrappers=1 commerce-final.mp4
```

## 问题排查指南

### 问题 1: INVALID_ASSET_PATH

**症状**: 上传素材后，后续操作报 "素材路径无效"

**检查**:
1. [ ] 确认 `uploadedPath` 已正确存储
2. [ ] 检查文件系统权限
3. [ ] 验证路径拼接逻辑

**修复**: 参考 `docs/OPENCLAW_MIGRATION_FIXES.md` 第 1 节

---

### 问题 2: 服务连接失败

**症状**: 请求返回 ECONNREFUSED

**检查**:
1. [ ] Video Agent 服务是否运行（端口 3020）
2. [ ] OpenClaw Gateway 服务是否运行（端口 18789）
3. [ ] 防火墙配置

**修复**:
```bash
# 检查端口占用
lsof -i :3020
lsof -i :18789

# 重启服务
npm start
```

---

### 问题 3: 编辑操作返回 422

**症状**: 某些编辑操作被拒绝

**检查**:
1. [ ] 操作是否在支持列表中
2. [ ] 提示词是否足够具体
3. [ ] 是否是组合操作（推荐）

**参考**: 查看 "支持的操作类型" 清单

### B. 常用 API 端点

- **创建项目**: `POST /api/commerce-chat` (action: init)
- **上传素材**: `POST /api/commerce-chat` (action: upload)
- **创作/编辑**: `POST /api/commerce-chat` (action: message)
- **预览视频**: `GET /api/commerce/{projectId}/revisions/{revisionId}/preview.html`
- **下载视频**: `GET /api/commerce/{projectId}/revisions/{revisionId}/commerce-final.mp4`
