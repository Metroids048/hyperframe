# S07 V2 · 一颗小球，一段运转
55秒 / 1920×1080 / 30fps / HyperFrames 0.8.33。

本版针对首版观感反馈重做：重新选择七段原片，缩短长时间手背遮挡；设计开场展开、全景、侧栏、同步局部放大及结尾五种画面关系。原片顺序和1倍速保持；底栏改为语义章节，短方向转场衔接画面，原声剪点使用20毫秒淡入淡出。不新增产品功效、生成镜头、配音或音乐。

index.html为可编辑合成；assets包含原素材、原声精剪轨及GSAP。source-selection.json记录全部源/成片时间。npm install之后运行npm run check和npm run render。此为reference-author效果样片，不是产品Agent全流程验收，旧工程与其他任务未改动。

检查覆盖：HyperFrames运行、布局、动效、对比度，实际MP4全解码、章节与片尾抽帧、原声映射相关性。不能以抽帧替代连续观看或听感，等待用户审阅。
