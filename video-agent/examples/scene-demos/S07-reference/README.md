# S07 握力球过程精剪 · 参考 Demo

55 秒 · 1920×1080 · 30fps。HyperFrames 0.8.33。

## 可编辑工程
`index.html` 保存章节、布局、动画与音画源时间映射；`assets/source.webm` 为本地原素材。运行 `npm install` 后 `npm run check`、`npm run render`。

## 删留方案
| 成片 | 原片 | 内容 |
|---|---|---|
| 0–12秒 | 0–12秒 | 初始操作与单手握持 |
| 12–32秒 | 42–62秒 | 握姿及遮挡/露出变化 |
| 32–41秒 | 66–75秒 | 开放托持及恢复握持 |
| 41–55秒 | 90.267–104.267秒 | 末段展示与真实收尾 |

其余区间在此候选中压缩，所有保留片段为1倍速、原顺序、同源音轨；不加音乐/配音。不用于训练指导。
