# 耳机 · 色彩与节奏

## Style Prompt
用这张白色有线耳机照片制作15秒竖屏新品风格展示。粉色、近黑和少量荧光黄绿；使用大标题、节奏型遮罩、照片窗口放大、耳罩局部细节、明确片尾。不把它说成无线耳机，不添加降噪、续航、音质参数或价格。文案：“调到喜欢的频率”“把音乐，放进今天”“近看每一个细节”“你的节奏，由你定义”。无旁白、无BGM。
