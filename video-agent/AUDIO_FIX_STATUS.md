1. **准备素材**
   - 从授权素材文件夹选择1-3分钟商品视频
   - 确保包含产品整体、细节和使用画面

2. **启动浏览器测试**
   - 打开 http://localhost:3020
   - 新建对话会话
   - 上传素材

3. **提交完整需求**（例如）
```
把这个商品素材制作成一条45秒左右、1080×1920竖屏的推广视频。

从原素材中选取6-8个有效镜头，开头3秒用实际产品画面吸引观看，
再展开三个产品特点，最后做自然的行动引导。

加入自然中文讲解、与讲解对齐的字幕和合适的背景音乐。
```

4. **监控验收**
   - 实时查看服务器日志
   - 等待任务完成
   - 下载并播放成片
   - 检查是否有配音和音乐

5. **检查证据**
   - 服务器日志：音频API调用记录
   - 项目目录：narration/music音频文件
   - 最终视频：实际播放验证

## 🚫 验收失败标准

任何一项出现即为失败：
- 最终视频无配音
- 最终视频无背景音乐  
- 服务器日志无音频API调用
- 项目目录无音频文件

## ✅ 验收通过标准

必须同时满足：
- 最终视频有清晰的中文配音
- 最终视频有合适的背景音乐
- 配音与画面/字幕同步
- 音乐音量合理（不盖过配音）
- 服务器日志显示成功调用音频API
