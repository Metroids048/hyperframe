# HyperFrames creative guidance

Use for designed titles, emphasis, numbered steps, comparisons, flow diagrams, data callouts, information graphics, brand open/close and other designed explanatory layers.

- Source fidelity is mandatory: labels, numbers, ratios, ordering and comparison direction must match the user's material or verified analysis.
- Keep created text/graphic meaning as editable project elements whenever the current adapter supports them; do not bake a new title over an old title and leave both visible.
- Design around a hero frame first. Reserve safe subtitle space and keep key graphics inside the visible frame for landscape, portrait and square outputs.
- One visual idea per beat. Prefer hierarchy and a few purposeful motions over decorative transitions on every cut.
- If an operation is not available in the current structured schema, do not smuggle it through HTML, shell or arbitrary files. Explain the boundary and preserve the current revision.
- When a number or comparison is visually emphasized, verify it against the source again before publishing.
