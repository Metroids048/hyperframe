# 本地视频 Agent Demo · v0.6

入口：http://127.0.0.1:3020/ 。刷新页面后，时长与镜头设置已实际生效。

## 使用路径

1. 写商品需求并上传图片，或点击「填入示例」。描述与素材相邻，品牌和卖点按需补充。
2. 在视频设置选择 15、30、60、90 或 120 秒，点击「生成视频」。自动规划分别为 4、5、10、15、20 个镜头。
3. 成片生成后播放、下载，或进入右侧「编辑分镜」。每镜可改标题、补充文案、时长、图片和版式，也可前移/后移、添加/删除镜头。
4. 点击「保存并生成视频」生成新版；时长随分镜累计，旧项目与视频保留。
5. 需要精细编辑时进入 HyperFrames 工作台，手工修改后的副本使用 Studio Export。

可上传 1–12 张 PNG/JPEG/WebP，每张最多 8 MB。镜头编辑支持 3–24 镜头、每镜 2–12 秒，总时长 10–180 秒；并非单纯把三幕拉长。七种版式为主视觉、左图右文、右图左文、细节特写、重点文案、双图展示、品牌收尾。配乐覆盖实际时长并在首尾淡入淡出。

## 看成品

页面新增「多镜头长片示例」区域：青序 60 秒 / 10 镜头，早屿 120 秒 / 20 镜头。点击可播放、下载、编辑。四个原 15 秒案例也继续保留。

新样片的素材来自已有商品图片，主要展示多镜头编排与工程编辑，不是实时视频模型生成的动作镜头。素材越充分，镜头的内容和视角越丰富。

## 当前边界

- 时长、镜头、文案、图片、版式、顺序实际生效。
- 实际输出仍是 16:9 横屏、1280×720。其他比例/画质仅保存需求，并明确提示。
- 自由输入使用本地规则，案例使用预置文案。实时生图/生视频接入为后续实施项，设计见 `docs/model-integration.md`。
- 当前尚未实现用户上传视频的自动裁切、语音生成或字幕对齐。
- Studio 副本未自动回写历史 MP4；本轮修改后仍渲染整片，尚无镜头渲染缓存。

## 运行与验证

执行 `./start-local.ps1` 启动；前端构建 `node scripts/build-web.mjs`。项目及完整日志保存在 `data/projects/<ID>/`，服务日志在 `outputs/`。

最新验收见 [验收记录](docs/acceptance-2026-09-09.md)。当前回归入口为 `npm test`，使用独立测试目录，包含真实 Chrome 输入、上传、生成、播放、分镜编辑与断线恢复。逐项结果见 `outputs/acceptance-latest.json`，正式长片和案例复核见 `outputs/release-smoke.json`。此前 `outputs/v6-tests.json` 保留为历史记录。

启动脚本已兼容 Windows PowerShell；新工程字体使用本机资源。状态连接连续失败三次后会暂停，恢复服务后点击「重新连接」。视频检查超过 60 秒或底层明确报错后，项目保留输入并允许重试。

HyperFrames 对同图多次复用和单轨多镜头给出结构警告，已确认是当前重复素材与扁平工程导致。运行、布局、运动和对比度检查通过；后续章节化合成和更多独立素材可改进工程组织。
