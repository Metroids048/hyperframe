# Commerce Design

## Style Prompt
1920×1080横屏。使用全幅整体、等比媒体加框外说明栏、不同表面的关系回顾三种构图。商品占视觉主导，文字区域不超过25%；全部媒体保持源比例，不额外放大已出框特写。字幕作为独立原生对象，使用caption-editorial-emphasis的稳定短句方式，按audio映射后的实测词时间显示。说明层仅用0.2秒显隐，接口短镜头直接显示，阅读阶段保持静止。所有线条仅分隔版面，不指向移动商品。字体来自运行时systemFamilies合同，不另行引入字体；许可及资源依赖由后续工程核验。

## Colors
- Background: #101419
- Foreground: #F2F5F7
- Panel: #1B222A
- Accent: #80C9DA

## Typography
- Microsoft YaHei

## Motion
- Intensity: 0.72
- Easing: power3.out
- Transition: cut

## What NOT to Do
- 不遮挡商品主体。
- 不编造商品事实或价格。
- 不使用随机、无限循环或依赖墙钟时间的动画。
- 不通过过量转场掩盖构图问题。
