# 原生工程包

在作品页面点击“导出”，生成当前所选版本的 MP4 与包含完整历史的 `history.zip`。点击“打开工程”选择该 ZIP，可在新的项目与数据目录中恢复版本、分支、原始输入、字幕、音轨、试听与确认声音，然后通过原有对话继续修改。

打包使用请求开始时捕获的项目历史快照，导出期间的后续修改不会改变该包的版本选择。相同文件以 SHA-256 去重，ZIP64 支持超过4 GB的包；当前受控包总量上限80 GiB，原始上传仍每个1 GiB、最多30个。80 GiB是实现边界，尚未用同等大小真实包完成压力验证。

包内 `package.json` 保存原生描述和引用，`blobs/` 保存按内容哈希命名的文件，原生 HTML 与修改记录均可追溯。导入不直接执行包里的 HTML；对路径、哈希、条目数量、压缩方式、原生数据和真实媒体进行校验，再使用本机固定运行时重编译和检查每一个历史版本。原 HTML 作为 `original-index.html.evidence` 保留。依赖不一致时不发布工程。

包不包含登录信息、运行缓存和系统字体。GSAP/HyperFrames 版本及文件哈希声明保留，字体使用目标系统已安装字体，不分发字体文件。来源署名与许可随素材和版本保留。

实际浏览器验证：`outputs/resume/portable-ui-2026-09-11T05-33-38.260Z/report.json`。包括下载、独立数据目录导入、三个版本逐对象比较、试听/确认/配音/字幕保留、恢复初始版后续改和完整播放。更多分支与大文件压力验证仍待补充。
