# Creative v2 architecture

Creative v2 adds an additive pipeline beside the legacy commerce compiler: EvidencePack → CreativeBrief/DESIGN/STORYBOARD → Scene Router → motion vocabulary → future native compiler. EvidencePack IDs are content deterministic and preserve provenance, rights, metadata, claims and constraints. Scene routes are purpose driven and support footage, image-motion, mixed, type-motion and custom-native.
