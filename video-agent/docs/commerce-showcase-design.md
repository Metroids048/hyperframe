# 电商示例与 WebUI

本轮按用户 2026-09-11 的新要求提前制作示例，与原交付合同的最终 D01—D08 验收分开记录。此前的文字动效、方形短片和宣传截图排版只是工程验证样片，不能代表电商成片质量。

## 页面

主流程保留一个需求文本框和可选图片、视频、音频附件。示例在对话上方，以“电商示例”下拉框和一个当前示例卡片展示，不增加必填配置。

“查看示例成品”载入已生成的输入、原生工程与固定 MP4，不创建模型任务。“这条视频是怎么做的”展开原始素材、实际制作过程、输出规格及来源；“按此输入重新生成”恢复原始文件与文字，等待用户发起新创作。原始输入和固定输出分别用 SHA-256 核验。

## 制作方向与当前优先级

用户后续进一步要求连贯的实拍商品宣传片，明确拒绝以图片补帧作为主片。因此暂停下列第 1 项的后续制作，第 2 项只保留现有可检查草稿，当前优先完成第 3 项的连续操作叙事。

1. **商品主视觉**：真实 AeroPress 照片，15 秒竖屏；深咖啡色、奶油白和红色，不对称照片构图、分层文字、线条及转场。
2. **细节与价格收尾**：同款真实照片，18 秒方形；整体、细节窗、配件布局、最后 3 秒的演示价格。¥199 仅为示例，不表示真实报价。
3. **连贯商品宣传片**：真实 Moka Alessi 冲煮视频，25 秒横屏；观察实际画面，选择研磨、装粉、组装、萃取和倒杯的连续动作，动态文字只作辅助，保留对应操作原声。源视频本身已剪辑，不能称为未剪辑原始 B-roll。

样片必须从真实 WebUI 上传素材、输入自然语言并调用实际模型产生。失败保留，不手改输出源码后冒充模型成功。实际通过检查和导出后才进入 `examples/commerce/presets.json`。
