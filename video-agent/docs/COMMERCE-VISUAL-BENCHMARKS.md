# 商品宣传片：视觉参照、动效实现与演示规则

本文件对应 `agent/commerce-demo-quality` 评审分支。原 main 上的示例只能证明基本编译和渲染通路，不能代表商品广告质量。本轮不扩展 WebUI，不接生图/生视频，不宣称达到专家相对85分。

## 2. 旧片为什么不能作为质量验收物

旧例以低细节示意商品图为主，商品与背景反差不足，文字像页脚，画面变化集中在整图缓慢推近，末尾长时间保持同一构图。这个判断是作品层面的问题，不能用 check passed、文件能播放或动效注册数量来反驳。

目标应该是：

- 商品照片本身清楚，前段就形成主体；没有摄影或三维素材，不能假装存在新的实拍角度。
- 文字是设计的一部分，标题、说明、CTA有明确层级；每幕只承担一个主要信息。
- 不同阶段使用不同景别或版式，运动引导观看而不是持续干扰。
- 不为凑30秒延长静帧。先做12–15秒有效样片，再按新增内容增加时长。
- 同一商品连续出现；局部裁切明确来自同一照片，不混用别的品牌/型号。

## 3. 把动效落到 HyperFrames

以下是本项目实现方案，不是对竞品内部实现的断言。

| 画面目的 | 实现 | 修改时保持可编辑的对象 |
|---|---|---|
| 大标题逐行揭示 | `.line-mask`裁切窗口 + GSAP `yPercent`；每行独立错开 | scene ID、line ID、文本、字号、起始帧 |
| 商品从画框展开 | 只移动照片容器和`clipPath`，不扭曲商品比例 | 图片引用、画框形状、取景范围、揭示时长 |
| 细节近看 | Sharp从同一原图裁切，两个错位照片窗口分别入场 | 原图哈希、裁切矩形、窗口布局 |
| 轻量镜头运动 | 图片内层缓慢scale和少量平移，版式外层不跟着晃 | 内层运动与外层布局分开 |
| 场景衔接 | 0.20–0.22秒方向遮罩，有重叠时间；上一幕不提前清空 | 场景起止、转场方向、重叠帧数 |
| 收尾 | 商品+大字+行动提示，箭头只做一次有限入场 | 片尾文案、CTA、持续时间 |

第一批参考片故意不加音轨。先独立审核画面，之后再以已授权的音乐完善声音层；不要用一段好听的音乐掩盖画面不足。

## 4. 三组演示输入与输出

构建脚本：`scripts/build-commerce-showcase.mjs`。
浏览器验证：`scripts/verify-commerce-showcase.mjs`。
生成目录：`examples/commerce-quality/`（仅在构建、检查与渲染通过后保存）。

### A. 香氛：编辑式产品广告，15秒

输入：Kateryna Naidenko的一张真实瓶身照片；所有局部来自同一张输入。保留原有商品标识。
视觉：奶油白、石墨灰、大字号衬线/中文字体、拱形画框、双细节图、克制推近。
演示重点：同一张照片也可以产生不同构图，而不是整张图从头到尾放大。
续改示例：只把最后一幕标题改为新的已确认短文案，保留前四幕的照片、节奏和取景。

### B. 耳机：色彩与节奏，15秒

输入：Kindel Media的白色有线耳机照片，加明确文案；不编造无线、降噪或续航。
视觉：粉色、近黑与小面积黄绿，PLAY大字、错位耳罩近景、画框尺度变化。
演示重点：两种文字层级与商品照片之间的运动配合；不是增加更多图标。
续改示例：让第三幕的细节图停留更久，保持总时长15秒并重新分配其他场景时间。

### C. 红色休闲鞋：时尚上新，12秒

输入：Dilma Obando的同一双红色休闲鞋照片，不添加价格和性能宣称。
视觉：深红、奶油白、大字、方向遮罩、鞋面/鞋底局部裁切、短而完整的收尾。
演示重点：更快节奏和稳定商品身份；不拿其他运动鞋补假角度。
续改示例：改成克制版本，减少方向性运动，文字和商品事实不变。

## 5. 演示时必须说实话

每组目录包含：`input.jpg`、`request.json`、`PROMPT.md`、`document.json`、`DESIGN.md`、原生HTML与素材、`final.mp4`、关键帧及技术报告。

这些是 **reference-author**：按明确输入和要求人工设计后，用固定源码构建的质量参考片。它们不经过原产品Agent自动规划，不可宣传成“当前任意一句话自动达到这种质量”。

推荐的三分钟演示：

1. 先展示三种输入素材和各自指令，明确使用了几张真实照片。
2. 播放12–15秒输出，指出产品、文字、细节和转场的对应关系。
3. 展示工程里的原图裁切、文本对象与分镜；需要展示实时对话续改时，必须使用已接通并真实测试过的工具，否则只展示待实现指令，不伪造执行过程。

技术测试与视觉认可分开：帧数、溢出、seek一致、照片运动可以自动测；节奏、审美、品牌表达和最终投放需要看完整片。浏览器报告不冒充人工完整观片。

原始照片里的tommy、GBG等标识不移除或冒充自有品牌。当前输出为非官方视觉演示。对真实商家交付时，应替换为商家已授权商品图和核实后的文案。无第三方竞品片段、无复制竞品音乐、无字体文件分发。
