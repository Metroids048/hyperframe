# 当前 Agent Skills 清单（10 个）

当前 registry 为 `config/skills/registry.json`。Skill 的作用分为两层：**project-adapter** 可以落到受控结构化操作；**prompt-router / composition-guidance** 会真实进入 Agent 规划上下文，但不会绕过执行器安全边界。

| Skill | 类型 | 当前用途 |
|---|---|---|
| timeline-edit | project-adapter | 裁切、保留、重排、插入、倍速、取景、导出意图 |
| speech-captions | project-adapter | 真实转写、字幕、旁白、已绑定旁白字幕同步 |
| visual-composition | project-adapter | 画幅、裁切、画中画、叠层、转场 |
| audio-mix | project-adapter | 配乐、音量、人声压低、淡入淡出、响度 |
| rough-cut | project-adapter | 静音/镜头候选和按内容粗剪规则 |
| hyperframes | prompt-router | HyperFrames 0.8.33 总路由、确定性预览/渲染、原生项目续改约束 |
| faceless-explainer | prompt-router | 主题/文章/笔记的讲解结构、旁白与句级字幕工作流 |
| hyperframes-creative | composition-guidance | 标题、强调、步骤、对比、信息图、品牌开/收尾 |
| media-use | composition-guidance | 真实截图/图片/视频的证据化选择、取景和展示规则 |
| hyperframes-animation | composition-guidance | seek-safe GSAP 动效、进入/退出、转场时序 |

所有外部来源、固定 commit、license、兼容版本、success criteria 都记录在 registry。上游快照只用于追溯和规则参考，不直接执行上游任意脚本。
