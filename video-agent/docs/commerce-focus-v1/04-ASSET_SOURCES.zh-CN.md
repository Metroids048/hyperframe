## 3. Codex 必须执行的下载与准入过程
使用页面提供的合法下载方式取得真实源文件，优先高清原版，不能把缩略图、网页HTML或低清预览保存成mp4冒充原片。没有可用直链就操作原页面，遇到访问限制如实记录；不购买、不绕过授权、不猜CDN地址。

保存到video-agent/assets/commerce-focus-v1/candidates下的对应分组。下载成功后先检查实际文件签名和媒体格式，计算SHA256，记录来源页、作者、取回日期、分辨率、帧率、时长与音轨；一次完整解码，再按内容实看。实际扩展名由格式决定，记录真实路径而非预填。

建立source-shot-index，记录每个可用区间、镜头作用、主体保护范围与事实；教程另外记录必要动作的源时间和先后依赖。对照业务合同确定是否充分，先批准素材才开始制作。没有观察能力要明确待人工，而不是无条件批准。

本轮商用目标要求素材用途与权利清楚。Pexels的免费商业许可不等于画面人物、品牌为我们背书；特别是耳机标识不得冒充自有品牌，不从页面标题推断性能。生成结果标注非官方演示也不自动解决所有权利。该项是应用的用途审核，不是法律保证。[L1][L2]

不建议把下载的原始图库批量提交公开Git仓库或随本包再分发。优先本地缓存、gitignore和可复现来源清单；原生工程对用户自有素材按许可打包，对不适合再分发的素材记录合法取得方式。没有字体文件随包分发。

## 4. 输入冻结与保留测试
第一批批准后冻结文件哈希与镜头索引，用于建立可编辑质量参考和实际Agent对照。然后每场景选一组未用于调模板的有效素材做保留测试，不提前把最终成片交给Agent只换标题。当前12个链接不意味着保留集已准备或已通过。

首批候选不足时，Codex应继续从同作者／同一器具系列找缺口，记录新增来源；不能无限重复下载不相关片段。需要用户拥有的实物完整素材才能满足时，具体说明缺哪个动作、角度和权利，不将缺口改成完成。

## 5. 给Codex的素材专项Prompt
读取assets.sources.json，获取真实视频并落入当前项目的candidates目录。优先检查耳机同作者组；教程组按同款和完整步骤分别实看，不混用备选组。将真实元数据、哈希和观察结论写回运行时素材清单，候选来源清单另保留原始状态作为记录。下载后未审核的素材不得approvedForProduction。形成A/B各一包足够支持合同的批准素材和一份缺口报告；没有高清完整动作就保持该分支阻断，继续其他工程任务，不生成占位图或虚假视频。
