# 零基础对话剪辑：当前可用流程

当前工作台以已有视频为起点：**上传视频 → 描述要求 → 查看预览 → 连续修改 → 导出**。不需要手动编辑时间轴。支持附加视频或音频；编辑工作台暂不接收图片、文稿附件，也不能在没有视频项目时凭文章直接创建完整视频。

## 开始一条视频

1. 打开 / 或 /edit，上传 MP4、MOV、WebM，或选择真实样例。每个素材和成片均不超过 10 分钟，最高 1080p。样例只载入原片。
2. 在聊天框写清目的与约束。例如：“剪成 30～45 秒，保留准备行动的完整对白与街头画面，保留原声，不加速。”内容选段会自动进行转写、抽帧和检查，首次分析通常比明确秒数修改慢。
3. 预览结果，点击“播放修改处”，或引用当前画面、时间范围、文字稿句子继续修改。可以撤销、恢复历史版本和对比原片。
4. 需要配音时提供台词、起点及声音要求，例如：“从第 1 秒添加男声旁白『行动即将开始』，语速 1.2 倍，并加对应字幕。”旁白按真实音频时长排布；指定区间不足时会说明冲突。
5. 满意后发送“导出当前版本”。最终 MP4 执行完整检查和严格渲染，导出期间仍可修改，新修改不会改变正在导出的版本。

## 常见要求

| 目的 | 可以发送的要求 |
|---|---|
| 精确裁切 | “删除开头 3 秒。” |
| 去停顿 | “删除超过 0.6 秒的停顿，保留完整句子。” |
| 字幕 | “为英语讲话添加中文字幕，保留原声，不添加旁白。” |
| 纠错 | “把字幕『旧文字』改成『新文字』，只改字和标点。” |
| 静音说明 | “在第 1 秒到第 3 秒添加顶部字幕『开始行动』，不要配音。” |
| 多素材 | 上传第二个视频后：“把第二个视频前 5 秒接到末尾，新片段静音。” |
| 配乐 | 上传音乐后：“用这段音乐配乐，音量 20%，人声处压低，前后淡入淡出。” |
| 画幅 | “改成 9:16，完整保留原画面。”需要裁切铺满时另行说明人物或区域。 |
| 复合编辑 | “删除前 3 秒，前 2 秒加标题『操作演示』，保留原声，不加旁白。” |

普通字幕与配音独立。只有明确关联生成旁白的字幕改词，才同步更新对应旁白。精确时间统一换算为 30fps 整数帧；字幕和音轨依据绑定规则跟随裁切及变速。复杂语义要求依赖实际素材证据及模型能力，自动检查不等于叙事和审美已经合格。

## 与文章中的完整创作流程有何差距

文章提出的“主题/文章 → 口播稿 → 最终配音 → 词级时间轴 → 分镜与素材 → HyperFrames”适合作为下一阶段创作路线。目前工作台尚未实现零素材项目、独立脚本定稿步骤、图片素材轨及任意 HTML 动效创作。不能把安装 HyperFrames skills 等同于自动拥有这些产品能力。

现有 Agent 使用受控时间轴操作编译 HyperFrames HTML，覆盖裁切、重排、字幕、配音、音乐、倍速、裁切构图、画中画与有限转场。外部视频/音频生成需要配置提供方，生成后作为素材导入；即使配置了提供方，也不等于整个文章创作流程已经实现。本地配音提供固定中文音色和语速，不支持任意声音克隆或情绪控制。

达到专家相对 85 分仍需完整的 24 项同素材盲评、专家参考片和至少两位独立真人评分。工程测试、真实模型执行和人工质量评估分别记录。
