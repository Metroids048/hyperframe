## 💡 核心经验总结

### 技术层面
1. **API 优先** - UI 只是展示层，核心能力在 API
2. **分页读取** - 大文件必须分块处理
3. **状态自愈** - 系统必须能从异常状态恢复
4. **合规优先** - 商业合规检查是特性不是bug

### 流程层面
1. **场景匹配素材** - 不是素材匹配场景
2. **避免功效声明** - 除非有真实证据
3. **通用场景策略** - 更容易通过合规检查
4. **质量标准量化** - 可验证的指标更有价值

### 用户体验
1. **中文本地化** - 所有面向用户的输出
2. **进度可视化** - 让用户了解系统在做什么
3. **错误可理解** - 技术术语要翻译
4. **操作可指引** - 给出具体的下一步建议
