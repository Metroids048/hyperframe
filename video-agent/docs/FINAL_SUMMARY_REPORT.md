### 对开发者

1. **质量控制是保护，不是障碍**
   - 系统拒绝不合规需求 = 避免法律风险
   - 严格的素材检查 = 保证内容真实性

2. **API 优先，UI 只是展示**
   - 所有核心功能应该有 API
   - 自动化优先使用 API

3. **大文件要合理组织**
   - 单文件超过 1000 行就该拆分
   - 关键逻辑不要放在文件末尾

### 对 AI 助手

1. **理解业务规则再判断问题**
   - 系统拒绝 ≠ Bug
   - 可能是合规检查在工作

2. **分页读取大文件**
   - 不要只看截断的前半部分
   - 完整理解再给建议

3. **用户友好的交互**
   - 翻译技术术语
   - 提供可操作步骤

### 对用户

1. **质量防线是特性**
   - 素材真实性检查
   - 商业合规验证
   - 内容质量把关
