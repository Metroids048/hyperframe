## 已解决的问题

### 1. ✅ 素材路径验证失败 (INVALID_ASSET_PATH)
**问题**: 上传的素材路径未正确存储，导致后续访问失败  
**根因**: `lib/creative/service.mjs` 中 `projectId` 和 `materialId` 初始化逻辑错误  
**解决方案**: 
- 修复 `createProject()` 确保返回 `projectId`
- 修复 `uploadAsset()` 正确存储 `uploadedPath`
- 统一使用 `uploadedPath` 替代 `originalPath`

### 2. ✅ 服务配置不一致
**问题**: Video Agent 和 OpenClaw Gateway 端口配置混乱  
**解决方案**:
- Video Agent: 固定端口 `3020`
- OpenClaw Gateway: 固定端口 `18789`
- 更新所有配置文件和测试脚本

### 3. ✅ 对话编辑流程理解错误
**问题**: 测试脚本假设 `message` action 返回 `jobId` 需要轮询  
**实际**: `message` action **同步返回渲染结果**，无需等待  
**解决方案**: 重写 `editVideo()` 函数，直接从响应中提取结果

## 发现的限制

### 不支持的操作类型

以下操作会返回 `422 UNSUPPORTED_MESSAGE`:

1. **添加新元素**
   - ❌ "添加字幕'高品质材料'在第5秒出现"
   - ❌ "在产品特写镜头添加字幕说明功能特点"

2. **模糊的位置调整**
   - ❌ "把标题移到屏幕中间位置"
   - ❌ "把标题移到上方"

3. **单独修改样式属性**
   - ❌ "把标题颜色改成蓝色"（仅改颜色）
   - ❌ "把背景音乐音量降低20%"

4. **时长调整**
   - ❌ "把视频缩短到12秒"
   - ❌ "换一首更有节奏感的背景音乐"

### 支持的操作类型

✅ **成功验证的操作**:

1. **修改标题文字**
   - ✅ "把标题改成'限时特惠'"
   - ✅ "把标题改成'品质保证'"

2. **组合修改标题**
   - ✅ "把标题改成'限时特惠'，字体改大，颜色改成红色"
   - ✅ "把标题改成'新品推荐'，颜色改成金色"

3. **调整视频节奏和结构**
   - ✅ "加快前5秒的节奏，突出产品亮相；后10秒放慢，展示细节"

## 架构发现

### API 设计

**端点**: `POST /api/commerce-chat`

**Actions**:

| Action | 用途 | 返回 | 是否异步 |
|--------|------|------|----------|
| `init` | 创建项目 | `{ projectId }` | ❌ 同步 |
| `upload` | 上传素材 | `{ materialId, uploadedPath }` | ❌ 同步 |
| `message` | 创作/编辑 | `{ state, document, rendered, video }` | ❌ 同步 |

**关键发现**: 
- 所有操作都是**同步的**，不需要轮询任务状态
- `message` action 直接返回完整的渲染结果
- 每次编辑生成新的 `revisionId`，支持版本追溯

### 数据流

```
用户输入
  ↓
POST /api/commerce-chat (action: message)
  ↓
OpenClaw Commerce Engine
  ↓ (LLM 理解 + HyperFrames 渲染)
同步返回 { state: "rendered", video: "..." }
  ↓
客户端直接获取视频 URL
```
