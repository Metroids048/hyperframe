   - 严格的素材检查 = 保证内容真实性

2. **API优先，UI只是展示**
   - 所有核心功能应该有API
   - UI是薄包装层
   - 自动化优先使用API

3. **大文件要合理组织**
   - 单文件超过1000行就该拆分
   - 或提供分页/索引机制
   - 关键逻辑不要放在文件末尾

### 对AI助手

1. **理解业务规则再判断问题**
   - 系统拒绝可能是正确行为
   - 先理解为什么拒绝
   - 不要急于"修复"

2. **完整读取大文件**
   - 使用分页策略
   - 关键逻辑可能在后面
   - 看完整代码再给建议

3. **用户友好的交互**
   - 翻译技术术语为通俗语言
   - 提供具体可操作步骤
   - 解释系统行为原因

### 对用户

1. **质量防线是特性**
   - 素材真实性检查
   - 商业合规验证
   - 版权合法性把关

2. **场景设计要务实**
   - 先调研素材库
   - 设计可实现的场景
   - 避免过度承诺

3. **理解系统保护**
   - 拒绝是为了保护你
