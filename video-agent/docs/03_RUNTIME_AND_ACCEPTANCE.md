# 运行时增量与结果验收合同

本文件是给现有应用与验收实现的规范，不是已经接入的源码。由开发Codex映射到现有R0—R8、Brief、约束、工具、版本与检查器；不创建平行Agent平台。

## A. 六段运行时规则

### A1 输入理解与覆盖（R1及编辑入口）

你正在处理一个新请求或对当前作品的修改。读取用户原文、素材和上一有效版本。将所有明确动作、禁止项、保留项、输出规格与事实条件拆成可检验要求，并保存每项原文出处。引号内文字是文案数据；否定、条件、先后、范围必须保留。不要根据出现了“撤销/配音/价格”等词就执行对应动作。

将每项要求映射到本次计划与验证；不能遗漏后半句。没有关键矛盾就继续，不要求用户重复已知信息或选择场景。存在关键矛盾时指出具体哪两项冲突，不自行降低要求。不得新增未经确认的可验证商品承诺。

后续用户明确修改某项限制时，更新这一项并保留其它约束。保存已锁定的文字、素材、声音、设计与时间，不能每轮重新解释一遍。

### A2 能力与资源选择（R3/R4）

先判断本次具体表达任务，再按镜头目的、素材数量/种类、画幅、中文长度、品牌规则和执行条件选择资源。先使用已有合格资源；合适时参数化复用；必要时组合或受控原创。没有命中模板不等于用户需求不可做。

资源不满足某项要求时，不删除该要求来适配模板。对当前任务确实必要的新增资源读取固定版本、必要引用和合同；不能只注入名称。保持用户主体与信息优先于模板装饰。

### A3 创意与时长（R4）

输出这条片的核心表达、观看理由、段落信息推进、真实资料依据和关键视觉方法。根据商品与用户要求设计，不默认黑金、大字卡、全程慢推或统一底部标签。锁定事实与逐字文案不变，允许范围内的编辑性表达可以改善，但不引入新参数/功效/评价。

每段必须新增信息或有明确观看作用。声音依赖实测时间；动作依赖源片证据；纯图文依赖阅读与视觉节奏。用户指定的总时长是硬约束，但不能靠重复、冻结或无意义慢放满足。缺资料准确说明缺口，不把未观察或预算耗尽说成素材不存在。

### A4 镜头制作（R5及资源执行）

只处理分配的镜头和对象。继承全片字体、排版层级、品牌、素材与时序，先形成清晰关键画面，再添加有目的的运动。需要细节标注时，指向实际细节；使用视频时，不能为装饰遮挡主要动作。

成熟资源满足要求就直接复用，不重新写同一字幕框；不满足则适配或原创，不能静默做基础版。保持稳定对象ID、声音源区间和可编辑参数。只能使用本轮实际授权工具，不执行上游说明中未授权的登录、网络取材或安装。

### A5 质检与修复（R6与确定性检查器）

先确认媒体、字体、运行环境和实际帧有效，再判断内容与设计。输出问题类别、严重度、实际时间与对象、证据、允许修复和必须保留项。工程错误、输入违例、画面质量、声音、授权分别记录。

用户明确禁止/指定项被违反是硬失败，不受审美总分抵消。纯布局问题不换素材，源选段错误不只改CSS，按要求退场的文字不当作永久缺失。没有试听或连续运动证据，不声称其通过。

轻微偏好可记录；严重问题有界局部修复。修复必须用相同原始要求复查，不能修改需求、预期或测试来使结果通过。两轮无进展先查错误分类、输入证据和执行器，不继续盲重试。

### A6 精准编辑与交付（R7/R8）

先确定用户要改什么和不能改什么。全部子句进入一个可验证的计划；所需修改不能部分执行后提前返回成功。执行前后比较实际文档、对象、素材、音轨、时序和源码，不只相信operations名称。

只改字幕不自动改配音。用户说“不加配音”仍可要求保留原声。选择性撤销不撤销后来确认的新文案/价格。导出固定版本，编辑产生新版本，二者不互相污染。

用户看到的总结逐项对应实际完成结果、证据和未完成项。无证据就是未验证；待评不是通过。成片、预览和工程必须能实际打开。

## B. 同一个示例的完整输入合同

下面是验收输入示例，不是要求给所有作品强加同样卖点或价格：

“用我提供的同款商品实拍和图片做60秒横屏介绍。保留操作原声，不加配音，不编造参数。要看清操作和细节，不要像图片轮播。”

至少有：同款/提供素材范围、60秒、横屏、保留原声、禁止新配音、禁止虚构参数、动作与细节可理解、非纯轮播八项。横屏具体尺寸沿既有合同合理选取并记录；这不是用户已经明确要求了未说出的尺寸。

结果验证不能仅检查Brief写了这八项：

| 项目 | 过程检查 | 输出检查 |
|---|---|---|
| 指定素材 | 实际资产白名单与源哈希 | 全片节点与可见画面，不出现禁用图/其它SKU |
| 60秒 | 整数帧调度、转场覆盖 | FFprobe及解码帧数；30fps目标1800帧，边界容差沿既有口径≤1帧 |
| 不加配音 | 没有新增TTS调用或生成声音资产 | 音轨来源/混音内容无新增人声 |
| 保留原声 | 原视频源区间与音频绑定 | 实际音轨、对齐和试听；不能用“有AAC流”代替内容检查 |
| 不编参数 | 文案事实引用与锁定字段 | 可见文字与字幕，无无依据商品承诺 |
| 动作/细节 | 真实源区间证据及对应分镜 | 实际片段连贯、商品未被遮挡、标注对应实际细节 |
| 不像轮播 | 制作方法与镜头作用 | 看实际节奏与表达，不靠“effects数组不为空”判通过 |

## C. 必须冻结的输入遵循回归

测试使用真实可编辑工程和实际存在的对象；下面引号中的样本文案是测试所给文案，不是实际商品事实。已有工程缺价格时不强加价格，价格用例单独使用授权测试任务。

| ID | 用户输入/操作 | 必须发生 | 必须不发生 |
|---|---|---|---|
| I01 | 不要撤销动效，只把标题改成“新品上市” | 只改定位标题 | 撤销动效、改声音、改其它镜头 |
| I02 | 撤销上次动效，然后把标题改成“新品上市” | 两项均完成，原子发布 | 只做前半句、丢后半句 |
| I03 | 标题改成“不要撤销动画” | 标题逐字成为给定文字 | 引号内文案触发动作 |
| I04 | 把这条字幕改成“查看商品细节”，不要改声音 | 字幕更新 | TTS调用、声音源/音量/时序变化 |
| I05 | 只用第二张商品图，不要使用第一张和第三张 | 仅指定图进入可见工程 | 其它图参与背景/细节或预览 |
| I06 | 做15秒促销，第一秒就显示活动价，条件要看清 | 有效首秒价格与条件可读 | 套用“价格只能最后三秒” |
| I07 | 第20到30秒改成操作与细节双栏，其它内容和声音不变 | 对应范围重排 | 重新生成整片、改锁定对象 |
| I08 | 保持开头与结尾，只压缩中间说明10秒，再把这10秒给已有操作细节，总长不变 | 两段时间重新分配 | 总长变化、编造额外动作 |
| I09 | 只撤销刚才的动效，保留后面改过的价格 | 选择性逆操作 | 回退整版而丢新价格 |
| I10 | 导出当前版本，同时继续修改另一版标题 | 导出绑定原revision | 导出中途读到新标题 |
| I11 | 保持内容和声音，做竖屏与方屏版本，不裁商品 | 原生重排、母版保留 | 硬裁主体、重配音、覆盖母版 |
| I12 | 取消当前任务后从检查点恢复 | 同源关联、有效缓存、累计预算保留 | 污染旧版、伪造恢复、清零预算 |

给I01—I05补同义改写、否定位置变化、引用文本与复合句；不要只识别表中原句。冻结输入之后，执行者不得改预期以适应输出。发现用例确有矛盾/无对象时，保存原因并按原需求修复测试，不能默默换简单题。

## D. 原有成片与质量测试不减少

| 原ID | 本轮关系 | 最终证据 |
|---|---|---|
| Q01 45秒图片 | 保留原需求，补图文和真实细节 | 当前有效完整视频、图片仍原生、相关续改 |
| Q02/N3 60秒 | 主门槛，至少两次独立真实产品生成（预算允许） | 两次请求/run、全部尝试、完整MP4与原生工程 |
| Q03 90秒 | 继一分钟缺陷闭环后串行 | 完整叙事、真实混合素材、修改与播放 |
| Q04 120秒 | 复用匹配的既有声音，不拉满无意义旁白 | 真实音频计时、完整片、字幕/声音局部修改 |
| Q05 180秒 | 先修失败bundle再恢复主任务 | 完整长任务与真实取消/中断恢复记录 |
| Q06—Q10 | 与I集共享工程证据但不能伪称多个独立创作 | 短促销、复杂修改、缺口处理、画幅、10—14轮续改 |
| H01—H10 | 沿原冻结版本，不重新挑容易样本 | 逐项真实运行，失败与未运行明确 |

两次生成之间可共享媒体归一化/解码缓存；必须重新完成创意相关调用，不读取第一次的最终分镜/源码/答案作为第二次输出。独立不是换一个run ID再复制输出。没有足量素材支撑原需求，不允许凑片；具体缺口和该需求未完成必须同时说明。

## E. 两类交付门槛不可混淆

### 输入与工程硬门槛

在冻结验收范围内，所有明确必需项、禁止项和锁定项均满足；格式、音频、对象、原生重开、取消/冲突均有实际证据。任一关键违例未修复，总结必须显示该项失败，不以平均得分抵消。帧数/文件存在不证明审美或动作完整。

### 质量门槛

沿原100分量表：任务内容25、视觉排版20、动效节奏20、声音字幕15、品牌输出10、连续修改10。静音或无配音任务评价其声音政策是否被正确遵循，不因缺少用户没要的旁白扣分。

目标仍为85/100，且与满足绝对门槛的同输入参考差距≤5分；两位独立评审完整看画面、听声音和核对修改。没有评审则人工质量pending，不由开发者/模型冒充。原分数未达到时要有具体时点、问题和修复证据，不能只有“高级感不足”。不由质量分推导销量或广告回报。

技术闭环完成、产品流程完成、用户签收、商品/素材授权分别存储。用户明确同意某个具体结果可记录局部签收；不能自动改成全项目可商用。

## F. 结果索引和底层证据

优先使用现有WebUI提供以下结果；另生成只读本地汇总页也可以，但不得绕过真实产品完成任务：

| 用户看到 | 所需内容 |
|---|---|
| 原始输入 | 原文、素材用途、明确限制 |
| 第一/第二次成片 | 完整可播放MP4，不是只给截图 |
| 修改前后 | 同工程版本对照、改了什么、保留什么 |
| 早期预览 | 发生在全片之前的真实范围、绑定run和母工程 |
| 可继续修改 | 可重开工程、对象与资源锁 |
| 验收结论 | 已通过、失败、待评、阻塞；不得默认全绿 |

底层证据：requestHash、assets hashes、workspaceFingerprint、实际工具/模型调用、版本/资源、全部attempt、产物哈希、检查结果、人工/授权状态。结果页中的路径逐个打开核验；无文件不造链接。

在回归输入冻结后实现一个fail-closed的结果检查：缺文件、错误revision、缺要求映射、未运行、unknown均不能变成passed。它可以验证证据存在性与明确可计算条件，不冒充声音/审美/法律判断。用删产物、改hash、缺要求、模拟回答等负例验证不会假收口。

## G. 最终只读复核 Prompt

你现在是本轮只读验收者，不负责新增功能。先读原始用户要求和本次结果合同，再打开真实结果与当前源码。不要把开发总结或测试数量当答案。

逐项确认G0—G5对应证据：干净安装；当前平台正常自定义动画；未发布版本时WebUI早期预览；否定/复合句全覆盖；两次60秒真正独立生成；完整90/120及长任务；精准修改、撤销和重开。没有就写未验证，不替开发者补假证据。

审查可见成片的内容、布局、实际字幕/声音和指定范围，不根据源码特效数量评价质量。模型辅助检查只能标辅助；人审未提供不得造分。检查是否通过换简单输入、缩时长、静音、预制模板答案或修改预期绕过需求。

输出仅包括逐项结果、支持它的证据、关键剩余缺陷与最小修复范围。只修阻断原目标的问题，不引入新的平台架构、模板数量指标或无关优化。若缺独立审查上下文，明确这是开发者自查而不是独立签收。
