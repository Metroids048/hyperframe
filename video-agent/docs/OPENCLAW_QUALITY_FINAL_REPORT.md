### 问题2: 为什么对话挂掉？任务流程卡住了，时间也很长？

**根本原因（已修复）：**

1. **Context容量问题**
   ```
   service.mjs: 1341行 (34,191 tokens)
   读取上限: 25,000 tokens
   实际读取: 前833行
   被截断: 后508行（包含关键中文逻辑）
   ```

2. **AI助手理解不完整**
   - 只看到一半代码
   - 关键的中文错误处理逻辑被截断
   - 需要多轮对话才能推进

**解决方案（已实施）：**
```javascript
// ✅ 分页读取大文件
const page1 = await Read('service.mjs', { limit: 800 });
const page2 = await Read('service.mjs', { offset: 834, limit: 507 });
```

**时间长的原因（正常行为）：**
- 素材观察和匹配：2-3分钟
- 商业合规检查：1-2分钟
- AI镜头规划：2-3分钟
- 视频编译渲染：3-5分钟
- **总计：8-13分钟（正常范围）**

### 问题3: 为什么返回英文和专业术语？

**根本原因：**

1. **后端实际是中文的**（在被截断的后半部分）
2. **AI助手直接展示了内部状态**
   ```json
   ❌ 错误展示：
   {
     "status": "waiting_external",
     "phase": "clean_run_init",
     "lastError": "OpenClaw gateway unavailable..."
   }
   ```

3. **应该翻译后展示**
   ```
   ✅ 正确展示：

   问题描述: OpenClaw网关暂不可用
   ```

**解决方案（已实施）：**
```javascript
const STATUS_TRANSLATIONS = {
  'waiting_external': '等待外部输入',
```

## 🎯 核心经验教训

### 对开发者

1. **质量控制不是障碍，是保护**
   - 系统拒绝不合规需求 = 避免法律风险
   - 严格的素材检查 = 保证内容真实性
   - 不要降低质量标准去"完成任务"

2. **API优先，UI只是展示**
   - 所有核心功能应该有API
   - UI是薄包装层
   - 自动化优先使用API

3. **大文件要合理组织**
   - 单文件超过1000行就该拆分
   - 或提供分页/索引机制
   - 关键逻辑不要放在文件末尾

### 对AI助手

1. **理解业务规则再判断问题**
   - 系统拒绝 ≠ Bug
   - 可能是合规检查在工作
   - 先理解为什么拒绝

2. **分页读取大文件**
   - 不要只看截断的前半部分
   - 关键逻辑可能在后面
   - 完整理解再给建议

3. **用户友好的交互**
   - 翻译技术术语
   - 提供可操作步骤
   - 解释系统行为原因

### 对产品经理

1. **质量防线是特性**
   - 素材真实性检查
   - 商业合规验证
   - 内容质量把关

2. **场景设计要匹配素材**
   - 先调研素材库
   - 设计可实现的场景
   - 避免过度承诺

3. **用户教育很重要**
   - 解释为什么被拒绝
   - 提供替代方案
   - 引导正确使用
