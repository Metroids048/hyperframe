## 本轮边界

Q1 只深做两类代表性质量样片：

* A：单品上新／种草的质感短片。优先验证商品主体、开头、视觉层级、动态字版、节奏和声音策略。
* B：商品卖点／使用演示的证据型视频。优先验证素材理解、动作连续性、步骤字幕、原声与信息表达。

其他已支持场景只做必要回归，不重新承诺八场景全量新片。保留 OpenClaw 原生 WebUI、上传与对话、视频服务、原生 HyperFrames 工程、历史 revision、恢复、自然语言再剪辑与导出链路；不重建框架、不迁移数据、不升级 HyperFrames、不新增平行 Agent 或任务系统。

## 样本与对照

样本选择必须绑定真实文件、asset ID、revision、源区间、SHA-256 和权利状态。每类样本保留三种标签：

* `BASE`：改动前现有 Agent 正常输出，不能用故意降级拼接片代替。
* `TARGET`：同一套原生工程／编译／渲染体系内的记录性目标样片，可做局部人工精修，但不能冒充自动能力。
* `AUTO`：质量改进后由现有 WebUI 正常入口、相同原始素材和用户要求生成。

自动结构检查、实际视听评审覆盖和用户最终验收分开记录。没有连续观片或实际听音时，状态只能是 `REVIEW_INCOMPLETE`／`NEEDS_REVISION`，不能写成听感通过、真人通过或正式发布通过。

## 质量闭环

缺陷必须绑定最终 MP4 SHA-256、revision、时间范围、证据文件、问题类型、严重度、影响对象和最小修改建议；修改只失效相关缓存并回到真正拥有字段的阶段。改变故事顺序、时长或源区间时，必须重新计算导演时间线、字幕、声音边界、HyperFrames 绑定和评审证据。

参考片只传递可迁移的镜头判断：开头、整体／细节关系、文字层级、切换动机、停留和声音关系。参考商品、品牌、文案、价格、卖点和事实永远不进入生产事实。抽帧不能代表完整运动或声音理解。

声音策略先于镜头编排：旁白、音乐、真实操作声三者按任务选择；音轨存在、响度和峰值检查不能代替听感。字幕来自实际旁白测量或用户原文，字幕修改默认不触发旁白重做。

## 交付标记

`READY_FOR_USER_ACCEPTANCE` 仅表示技术、视听覆盖和局部修复证据齐备，用户验收仍为 pending；覆盖不足写 `REVIEW_INCOMPLETE`，外部权限／素材／供应商阻塞写 `BLOCKED`，主要缺陷未修写 `NEEDS_REVISION`。Q1 的目标是证明两类样片真实变好、换商品仍能工作、三轮局部续改保留满意内容；不以未经校准的分数或文件数量代替成片质量。
