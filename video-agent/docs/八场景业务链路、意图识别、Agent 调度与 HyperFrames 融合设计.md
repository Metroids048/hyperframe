## S02 本次实际输入与链路

素材来自项目根目录 `素材/ASUS_PROART_RTX_4070_Ti_Unboxing_-_By_INVADERPC.webm`。目标为 35 秒横屏显卡详情片，面向关注外观和接口布局的装机用户。原片无声音；使用本地中文旁白，不添加背景音乐。

实际设计：完整显卡 → 正面风扇与外壳 → 叶片近看 → 正侧邻接 → 侧边连接座 → 端部接口 → 背板及开口 → 外轮廓衔接 → 整体回顾。结构名称必须能由画面证明，不宣称散热效率、噪声、性能、尺寸或价格。

已经发现并修过的输入问题包括：把“HyperFrames 资源”误识别为资源名称；自拟旁白过长与接口镜头容量冲突；背板镜头末尾跨入侧面。目前继续修复真正落地的音轨排程、字幕和画面表现。源片、旧声音、失败证据与历史工程均保留。
