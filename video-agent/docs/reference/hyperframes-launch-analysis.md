# Official launch composition analysis

只读分析了 `hyperframes-launches` 的 `hyperframes-launch`、`inspector-launch` 和 `cloud-render-launch` 的 `STORYBOARD.md` 与目录结构。共同规律是：先用清楚的 thesis/hook，再让一个视觉机制贯穿多个镜头；媒介不是填充而是证据；文本层级短而明确；转场服务叙事；同一 UI/画布在后续镜头持续演化；结尾形成可识别的 lockup。Inspector 明确记录哪些设计仍是 placeholder，说明高级作品也会把未实现内容标为未完成。

可执行规则：开头 2–4 秒提供主体或强兴趣；每幕必须新增理解；同一对象跨幕保持锚点；视觉世界变化要有业务理由；持续操作不靠卡片和进度条伪装；素材、音效和字体的授权与源码分开核对。Commerce V3 用这些规则约束上新和演示，但不复制官方品牌、媒体或固定时长。
