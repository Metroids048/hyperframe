# 给非技术同事的 V3 全面理解

HyperFrames 可以把普通网页结构拍成视频：HTML 是画面，`data-start`/`data-duration` 是时间轴，CSS 是视觉，GSAP 是可定位的动效。它不是把 MP4 贴进页面，而是保留可编辑对象，之后可以换镜头、改标题、改颜色、改字幕、调时长、撤销重做，再导出。视频和音频分开管理，声音不会因为改字幕就凭空生成。

V3 外层是业务 Agent。用户只选“单品上新”或“产品演示”，说一句自然语言，选择或上传素材目录。Agent 先看真实素材，再建立证据、挑选源区间、做创意方向和故事计划，随后搜索 HyperFrames Catalog。Catalog 是官方 0.8.33 的只读能力地图；找到资源不等于直接执行，只有受审的本地适配器可以进入原生工程。

“单品上新”回答消费者“这是什么、为什么值得继续看”：前几秒建立商品，接着用真实使用或细节形成印象，最后完整收尾。没有价格、参数、认证或评价，就不会自行编写。“产品演示”回答“怎么做”：先找初始状态、动作、依赖和完成状态；能删等待，不能删必要动作，不能倒放、换序或用图片假装操作。字幕和标注绕开手部、接口和商品关键结构。

质量有三道门：可处理素材与业务准入、候选片技术/业务检查、正式交付。MP4 存在或渲染成功只表示候选可能完成；正式交付还要求当前版本的证据、权利、完整视觉/听感审查以及真实操作者确认。自动关键帧审查会明确没有覆盖连续动作和听感的地方，不会冒充真人。

Pippit 的可观察启发是“先完成营销任务，再让人编辑”：prompt 和素材进入 Agent，先形成策略、脚本、视觉，再进入可编辑和导出。V3 已实现两个本地素材场景、原生工程、资源 provenance、预览/修复门禁、MP4 候选、撤销重做。链接自动研究、批量社媒发布、广告分析、Avatar 和生成新镜头仍不在本轮。

常用验收问题：商家能否确认商品没混错？第一次观看能否快速看懂？剪辑师能否找到每个源时间、保护区和可编辑文字？最后实际播放整个 MP4，检查片头、每个切点、字幕变化、动作连续性、声音尾部和片尾。没有真人确认时，页面应显示“待审”，不能显示“正式合格”。
