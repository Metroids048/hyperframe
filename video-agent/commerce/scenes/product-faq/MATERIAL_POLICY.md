# MATERIAL_POLICY

F.4 完整业务链路

输入问题 → 判断问题类型和观众 → 找到答案依据 → 确认限制 → 选择最直接的证据 → 先回答再解释 → 检查问题是否真正解决 → 修改与交付。

段落

观众应该获得什么

制作重点

问题

本片回答哪一件事

保留原问题含义，不偷换成营销主题。

简答

核心结论

语气与证据强度相匹配。

证据

为什么这么说

对应真实动作／细节／确认资料。

限制

哪些情况不适用或未确认

不把个例扩大为普遍承诺。

收尾

需要核对或下一步做什么

不用强 CTA 把关键限制挤掉。

F.7 缺料和验收

没有证据时先指出无法确认的部分，可输出问题整理和补料建议，不能编测评结论。需要尺寸对照但没有尺寸数据时，说明必须补充哪些尺寸，不能猜测兼容性。

合格标准是问题被直接回答、证据可对应、结论不过度、限制可见、没有换题或用空泛口号回避问题。
