# STORY_GRAMMAR

hook → identity → usage → supported_detail → hero_return → ending。结构可变，不强行补空镜头。前2—4秒看到商品或产生明确视觉兴趣。无需Logo开场，无价格不写价格；每幕新增信息，结尾回到完整商品。

## V2 新品种草 30 秒导演结构

默认商业结构为 Hook → 生活场景 → 产品出现 → 卖点 → 体验 → 购买理由。它是信息职责，不是固定六幕模板；素材足够时可以拆镜头，素材不足时缩短，不重复平移图片凑时长。

- 0—3 秒必须同时完成明确兴趣点和真实商品/结果证据，不用 Logo、空泛氛围或通用标题占用开场。
- 生活场景用于让目标用户代入，不得用无关库存 B-roll 代替本商品使用证据。
- 产品出现后只优先表达 1—3 个有证据的卖点；每个卖点必须绑定 ProductBrief ID 和源画面。
- 字幕分别承担 hook、benefit、proof、reason-to-buy、CTA，不复述画面说明。
- 体验段优先保留真实动作、原声或结果；购买理由是前面证据的收束，不新增性能。
- 每个 DirectorTimeline shot 必须填写商业目的、成功标准和 HyperFrames intent。前三秒、商品曝光和卖点证据为独立质量底线。
