# Hyperframe 本地视频工作台

一个用于电商视频创作的本地工作台。首页提供生成目标、画幅和场景设置，可从顶部作品菜单预览示例成片并下载原生工程。仓库带有源码、示例、固定版本的上游子模块，以及工作区内容快照。

## 本地启动

安装 Python 3.10+ 和 Node.js 22+。从 Git 检出或下载 ZIP 后，在仓库根目录运行以下命令。

```sh
python start.py all
```

启动器安装锁定的依赖，恢复运行所需的工程和素材，构建 WebUI 并显示访问地址。端口冲突时会选择新端口。首次恢复会读取分块资源，请预留下载和磁盘空间。

在首页的作品菜单选择「米家相机 · 广告精剪 V2」可查看播放与下载流程。该示例使用参考作者的作品，适合验证工作台的交付入口。生成质量以实际任务和对应成片为准。

## 开发者同步

有写权限的维护者可运行 `python start.py push` 或 `python push.py` 同步工作区。它与本地预览分开执行。同步脚本排除本机配置和凭据，换设备后在本机重新配置。
